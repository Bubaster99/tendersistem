## Технические правила
- Стек: Next.js (App Router) + TypeScript, PostgreSQL + Prisma, Tailwind, Docker Compose.
- Все секреты и ключи — только в `.env` (в git не коммитить, держать `.env.example`).
- Права доступа проверяются на сервере в каждом запросе. Суммы и файлы КП до дедлайна не отдаются никому — это главное правило безопасности, покрой его тестом.
- Время — серверное, часовой пояс Europe/Moscow.
- В режиме разработки письма не отправляются, а пишутся в консоль.
- Интерфейс только на русском. Все экраны подрядчика должны нормально выглядеть на телефоне (375 px).
- Дизайн — цвета и шрифты из раздела 10 SPEC.md.
- Никаких зарубежных сервисов для хранения данных пользователей (152-ФЗ): база и файлы — только на нашем сервере в РФ.
