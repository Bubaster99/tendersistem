# Промпты для Claude Code по этапам

Правило: **одна новая сессия = один этап.** Копируйте промпт, ждите план, отвечайте «ок», проверяйте результат по инструкции Claude. Если что-то не так — описывайте симптом своими словами и прикладывайте скриншот.

---

## Этап 0 — старт

```
Прочитай SPEC.md и CLAUDE.md. Ничего пока не пиши в код.
Перескажи в 10 пунктах, как ты понял задачу, и перечисли вопросы, если есть.
Затем предложи структуру проекта и план этапа 1.
```

## Этап 1 — каркас и вход

```
Делаем этап 1 из SPEC.md: каркас проекта и вход по ИНН + код на почту.
- Next.js + TypeScript + Tailwind + Prisma + PostgreSQL в Docker Compose, запуск одной командой.
- Модели Company, User, LoginCode.
- Экран входа как в разделе 4.1: ИНН → карточка компании из DaData → email → согласие → код → вход.
  Если ключа DaData нет в .env — используй заглушку с тестовыми данными.
- В разработке код входа пиши в консоль.
- Пустая страница «Объекты» после входа, шапка с навигацией: Объекты, Тендеры, Мои заявки, Контакты, Подписка.
- Цвета и шрифты из раздела 10.
В конце заполни раздел «Команды» в CLAUDE.md и напиши, как мне проверить.
```

```

ежедневный бэкап базы и файлов, инструкция для меня по шагам — что купить, куда нажать, какие команды вставить.
Перед этим проведи ревью безопасности всего проекта: права доступа, запечатанные КП, лимиты входа, загрузка файлов, секреты.
Выдай список найденных проблем и исправь их.
```
